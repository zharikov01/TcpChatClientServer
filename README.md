# TcpChatClientServer

Задание на 06.11.2026 - доработка чата на сетевых потоках TCP из классной работы
(30.10.2026): клиент реализован как WPF-приложение.

## Состав решения

| Проект           | Назначение |
|------------------|------------|
| TcpChatServer    | сервер чата из классной работы, порт 8888; исправлен прием сообщений |
| TcpChatClient    | консольный клиент из классной работы (для проверки чата с несколькими участниками) |
| TcpChatWpfClient | WPF-клиент: сообщения и команды вводятся в TextBox, сообщения сервера и команд клиента выводятся в TextBlock |

Команды клиента (выполняются на клиенте, на сервер не передаются):
`@help`, `@about`, `@clear`, `@exit`
